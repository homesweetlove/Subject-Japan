## 검증 기준

- `npm ci`, `npm run typecheck`, `npm test`, `npm run build:web`, `npm run build:bundles`, `npx expo-doctor`.
- Android·iOS 원시 코드 변경: GitHub Actions **Native builds**의 Android 및 iOS 시뮬레이터 컴파일 결과가 별도로 필요.
- 사진 금액 OCR은 실제 갤럭시 기기에서 가격표·영수증/권한 거부/촬영 취소/잘못된 후보 선택을 점검해야 합니다.
- FeliCa는 1·2·19·20건 기록, 0건, 카드 이동, 태그 제거, 지원하지 않는 카드, NFC 꺼짐, iPhone entitlement를 시험해야 합니다. 어떤 상태 오류라도 부분 데이터가 저장되면 안 됩니다.
- 멤버십은 바코드 스캐너와 실제 매장 시스템 수용 여부를 별도 확인해야 합니다.

테스트 통과와 기기 검증 완료는 별개입니다. CI 결과와 릴리스 링크는 최신 실행 완료 후 확인합니다.
