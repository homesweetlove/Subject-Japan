# 로컬 데이터 처리

## 수집 범위와 목적

- 닉네임: 화면 개인화. 선택 입력이며 실명이 필요하지 않습니다.
- 상의·하의·신발 사이즈: 쇼핑 문장에 사용자가 저장한 표기를 치환합니다.
- 번역 원문·번역문·시각: 최근 기록과 즐겨찾기를 다시 사용하기 위해 저장합니다.
- 테마·온보딩 상태: 앱 재실행 시 선택을 유지합니다.

모든 앱 데이터는 `subject-japan.local.v1` 로컬 키 아래 저장합니다. 앱이 자체 서버로 이 데이터를 전송하지 않습니다. 번역은 ML Kit 기기 내 추론을 사용합니다. Google 모델 다운로드 및 ML Kit SDK 진단 통신은 별개입니다. 네트워크 통신이 전혀 없다는 보장은 하지 않습니다. 출시 전 SDK 데이터 공개 사항과 스토어 개인정보 양식을 다시 확인해야 합니다.

기록 100개를 넘으면 가장 오래된 최근 기록을 제거합니다. 즐겨찾기는 기록과 별도로 보존하고 100개 초과 시 기존 항목 삭제를 안내합니다. 프로필 사이즈 변경이 이전 번역 기록의 내용을 바꾸지는 않습니다.

## 사용자 제어

- 첫 실행 입력을 건너뛰어도 앱을 쓸 수 있습니다.
- 사용자 페이지에서 언제든 사이즈를 수정하거나 비울 수 있습니다.
- 최근 기록 삭제는 즐겨찾기를 유지합니다.
- 사용자 페이지의 전체 삭제는 확인 후 프로필·사이즈·기록·즐겨찾기·설정을 초기화합니다.
- 전체 삭제 후에도 ML Kit 언어 모델 파일은 다시 사용할 수 있도록 기기에 남습니다. 앱 삭제 시 모델을 포함한 앱 데이터가 제거됩니다.
- 앱 삭제/기기 변경 후 복구용 계정 서버는 없습니다.

Android 앱 백업은 `allowBackup: false`로 설정합니다. iOS는 `RCTAsyncStorageExcludeFromBackup: true`로 AsyncStorage의 iCloud 백업 제외를 명시합니다. 운영체제·제조사에 따른 기기 전송 정책은 출시 디바이스에서 확인해야 합니다. 웹 미리보기는 해당 브라우저의 localStorage를 사용하므로 공용 브라우저 사용 후 전체 삭제를 권장합니다.

AsyncStorage는 앱 수준 암호화 저장소가 아닙니다. 앱 샌드박스/기기 보안에 의존하며 자격증명·여권·카드번호를 저장하도록 설계하지 않았습니다. 클립보드 복사는 사용자가 누른 경우에만 수행하며 이후 클립보드 처리는 OS 설정에 따릅니다.

## 향후 서버 연동 원칙

인증 프로필과 로컬 쇼핑 프로필을 분리합니다. 카메라 이미지·음성·위치·프로필 업로드는 기능 도입 시 별도 동의와 보관 정책을 마련해야 합니다. 클라우드 번역 제공자를 추가한다면 전송되는 원문과 제공자를 명확히 표시하고, 현재의 기기 내 처리 안내를 그대로 재사용하지 않습니다.
