# Galaxy (Android) 실기기 검증 체크리스트

이 문서는 **자동 검사 완료를 의미하지 않습니다.** Android 전용 기능을 실물 기기에서 확인하기 위한 절차입니다. iOS 구현은 이번 변경 범위에서 제외했습니다.

## 설치

1. GitHub Actions의 **Android test APK** 워크플로를 해당 브랜치에서 수동 실행합니다. 워크플로가 성공하면 Releases의 `Subject-Japan-android-test-arm64.apk`을 설치합니다. Actions 계정 제한 시 APK가 생성되지 않을 수 있습니다.
2. 테스트 APK는 `com.subjectjapan.app.preview` 패키지로 별도 설치되며 기존 앱 데이터와 분리됩니다.
3. Android NFC를 켜고 Suica / PASMO / ICOCA 실물 카드를 준비합니다. 같은 휴대폰 안의 모바일 교통카드는 직접 스캔할 수 없습니다.

## 1. 교통카드 NFC

- [ ] NFC 없는 기기에서 읽기 시 명확한 오류 안내가 나타난다.
- [ ] NFC를 끄면 `꺼짐` 상태를 표시하고 켠 후 상태 새로고침에서 활성화를 확인한다.
- [ ] NFC-F가 아닌 태그에는 지원하지 않는 카드라는 안내가 나온다.
- [ ] 실제 일본 교통카드 잔액·최근 내역을 카드 측 조회 정보와 대조한다.
- [ ] 1건, 여러 건, 20건, 빈/부분 기록을 각각 점검한다. **현재 구현은 최대 20블록을 모두 읽고 실패 시 전체 스캔을 거부하므로, 카드별 기록 응답을 확인하기 전에는 성공을 보장할 수 없다.**
- [ ] 중간 제거, 60초 시간 초과, 취소 직후 다시 스캔 및 백그라운드 전환이 앱을 멈추게 하지 않는다.
- [ ] 화면에 보이는 것은 **마지막 스캔 잔액**이며 실시간 잔액으로 오인되지 않는다.

## 2. PAY 가격표 OCR

- [ ] PAY → 결제·할인 → 갤럭시 카메라로 가격표 읽기.
- [ ] 세금 포함/별도, ¥/￥/원문 円, 천 단위 쉼표를 점검한다.
- [ ] 후보 금액을 눌러야 금액 입력란이 바뀐다. OCR을 실행한 것만으로 계산/지출/저장이 바뀌면 안 된다.
- [ ] 카메라 거부, 사진 취소, 빈 이미지, 회전/흐림/세로쓰기를 점검한다.
- [ ] 환율이 오래된 상태는 기존 경고대로 표시된다.

## 3. PAY 영수증 OCR

- [ ] PAY → 면세·세관 → 갤럭시 카메라로 영수증 읽기.
- [ ] 합계·지불 금액과 현금 맡긴 금액·거스름돈·세금·포인트가 섞인 실제 영수증을 촬영한다.
- [ ] 추천 금액을 선택한 뒤 매장명·품목·면세 적용 여부를 직접 검증하고 **영수증 등록**을 누른다.
- [ ] OCR 결과만으로 매장명·세금·면세 대상·면세 적용 유무를 단정하지 않는다. 5,000엔 초과만으로 면세 적용 체크가 켜지지 않아야 한다.
- [ ] 앱 재시작 후 등록된 내역이 그대로 유지된다.
- [ ] 갤러리 사진 원본은 변경·삭제되지 않는다. 임시 카메라 파일만 정리된다.

- [ ] `npm run build:bundles`
- [ ] Android Gradle release APK 빌드
- [ ] 갤럭시 실기기에서 카메라 / NFC 기능 확인
